# Party Mixes

Place your already-mixed party tracks in this folder.

Naming convention:
- `mix-01.mp3`
- `mix-02.mp3`
- `mix-03.mp3`

These files are played as-is; VIBE FLOW will not remix or split them. The Party with AI feature will display numbered names rather than the original filenames.

Supported formats planned: MP3, WAV, M4A, OGG, FLAC, AAC.
